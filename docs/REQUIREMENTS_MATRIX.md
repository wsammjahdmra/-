# مصفوفة المتطلبات الوظيفية (REQUIREMENTS MATRIX)
**المرجع:** المواصفات الوظيفية لمنصة عقار — الإصدار الثالث، والتصميم التقني — الإصدار الرابع.

| المعرف | الوحدة | الصفحة المرتبطة | الصلاحية المطلوبة | الجدول / الخدمة | حالة التنفيذ | نوع التحقق والاختبار |
|---|---|---|---|---|---|---|
| **REQ-PUB-01** | البوابة العامة | PUB-01 (الرئيسية) | عام للجميع (زائر+) | Listings / Settings | منفذ ومختبر | تصفح، أقسام العقارات، إعلانات مميزة، فلاتر سريعة |
| **REQ-PUB-02** | محرك البحث | PUB-02 (البحث والتصفية) | عام للجميع | Listings / Properties | منفذ ومختبر | الفرز، التصفية بالمدينة والحي والسعر والمساحة، عداد دقيق |
| **REQ-PUB-03** | بطاقة وتفاصيل الإعلان | PUB-03 (تفاصيل الإعلان) | عام للجميع | Listings / Media / Licenses | منفذ ومختبر | معرض الصور، الترخيص، بيانات المعلن، إعلانات مشابهة |
| **REQ-PUB-04** | المشاريع والوحدات | PUB-04 (المشاريع العقارية) | عام للجميع | Projects / Units | منفذ ومختبر | فك الارتباط بين المشروع والإعلان الفردي، تفاصيل الوحدات |
| **REQ-PUB-05** | التحليلات السوقية | PUB-06 (المعلومات السوقية) | عام للجميع | Market_Indicators / Gemini | منفذ ومختبر | مؤشرات متوسط الأسعار حسب المدينة والحي، مع Maps Grounding |
| **REQ-PUB-06** | الدعم والبلاغات | PUB-07 (المساعدة والبلاغات) | عام + مستخدم مسجل | Report_Cases / Tickets | منفذ ومختبر | تقديم بلاغ مع رقم مرجعي وحماية ضد الإغراق |
| **REQ-ACC-01** | المصادقة والجلسات | ACC-01 (التسجيل والدخول) | عام | User_Account / Sessions | منفذ ومختبر | تسجيل، دخول، تبديل الأدوار للاختبار الواقعي |
| **REQ-ACC-02** | الملف الشخصي | ACC-02 (الملف الشخصي) | مستخدم مسجل | User_Account | منفذ ومختبر | عرض وتعديل البيانات، إدارة الحساب |
| **REQ-ACC-03** | المفضلة والبحث المحفوظ | ACC-03 (المفضلة والبحث) | مستخدم مسجل | Favorites / Saved_Searches | منفذ ومختبر | إضافة وإزالة المفضلة، حفظ معايير البحث |
| **REQ-ADV-01** | لوحة إعلانات المعلن | ADV-01 (إعلاناتي) | معلن فرد / مدير منشأة / وسيط | Listings / Status_History | منفذ ومختبر | فرز الإعلانات حسب الحالة، المشاهدات، طلب الترويج |
| **REQ-ADV-02** | إنشاء وتعديل الإعلان | ADV-02 (إنشاء الإعلان) | معلن فرد / مدير منشأة / وسيط | Listings / Properties / Media | منفذ ومختبر | نموذج متعدد الخطوات، حفظ مسودة، رفع وسائط، تراخيص |
| **REQ-ADV-03** | مسار حالة الإعلان | ADV-03 (سجل الحالة) | معلن فرد / إداري | Listing_Status_History | منفذ ومختبر | خط زمني للانتقالات، أسباب الرفض أو الإيقاف |
| **REQ-ADV-04** | باقات الترويج والدفع | ADV-04 (الترويج والرسوم) | معلن / منشأة | Payment_Orders / Invoices | منفذ ومختبر | اختيار الباقة، حساب السعر خادميًا، منع التكرار، فاتورة |
| **REQ-ORG-01** | ملف المنشأة العقارية | ORG-01 (ملف المكتب) | مدير منشأة | Organizations / Memberships | منفذ ومختبر | بيانات المنشأة، رخصة فال، إدارة الفريق |
| **REQ-ORG-02** | إدارة أعضاء المنشأة | ORG-02 (أعضاء المكتب) | مدير منشأة | Org_Memberships | منفذ ومختبر | دعوة عضو، تعيين الدور والنطاق، تفعيل أو تعطيل |
| **REQ-ADM-01** | لوحة التشغيل الإدارية | ADM-01 (لوحة التشغيل) | مدير نظام / مشرفون | Dashboard Metrics Service | منفذ ومختبر | إحصائيات حية مستخرجة من قاعدة البيانات (ليست أرقاماً ثابتة) |
| **REQ-ADM-02** | مراجعة واعتماد الإعلانات | ADM-02 (مراجعة الإعلانات) | مشرف محتوى / امتثال | Listings / Status_History | منفذ ومختبر | فحص الإعلان، قبول، رفض مع سبب إلزامي، طلب استكمال |
| **REQ-ADM-03** | معالجة البلاغات | ADM-03 (إدارة البلاغات) | مشرف محتوى / دعم | Report_Cases | منفذ ومختبر | حالات البلاغ (جديد، قيد المراجعة، مصعد، مغلق)، توثيق الإجراء |
| **REQ-ADM-04** | الامتثال والتكاملات | ADM-04 (الامتثال والتراخيص)| مسؤول امتثال وتراخيص | Integration_Logs / Lic_History | منفذ ومختبر | فحص سجلات الاستدعاءات، إعادة المحاولة الآمنة |
| **REQ-ADM-05** | العمليات المالية والفواتير | ADM-05 (المالية) | مسؤول مالي / مدير نظام | Payments / Invoices / Refunds | منفذ ومختبر | فواتير ضريبية، تسويات، طلبات واعتماد استرداد |
| **REQ-ADM-06** | المستخدمون والصلاحيات | ADM-06 (المستخدمون والأدوار)| مدير نظام | User_Accounts / Roles | منفذ ومختبر | بحث، تعديل الصلاحيات، تعطيل/تفعيل الحساب |
| **REQ-ADM-07** | سجل التدقيق الإداري | ADM-07 (سجل التدقيق) | مدير نظام | Audit_Events | منفذ ومختبر | تسجيل غير قابل للتعديل لكل عملية حساسة مع المنفذ والوقت |
| **REQ-SET-01** | تخصيص المنصة والهوية | الإعدادات العامة | مدير نظام | System_Settings | منفذ ومختبر | تغيير اسم المنصة، الشعار، الألوان، العملة، الضريبة ديناميكياً |
| **REQ-MAP-01** | تكامل خرائط Google Maps | خريطة الأحياء والمشاريع | عام للجميع | Google Maps / Gemini Grounding | منفذ ومختبر | استخراج معالم الحي والمرافق وروابط Maps الحقيقية |
