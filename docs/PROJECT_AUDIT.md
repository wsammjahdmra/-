# تدقيق المشروع وفحص البيئة (PROJECT AUDIT)
**تاريخ الفحص:** 2026-10-14  
**اسم المنصة:** منصة عقار (Aqqar Platform)  
**بيئة التشغيل:** Node.js 22 LTS / React 19 / TypeScript 7 / Express / Tailwind CSS / Vite  

---

## 1. فحص بنية المجلدات والملفات الأولية
- **المجلد الجذري:** يحتوي على `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `metadata.json`, `.env.example`.
- **مجلد `src/`:** يحتوي على نقطة الدخول `main.tsx` و `App.tsx` و `index.css`.
- **الاعتماديات المتوفرة:**
  - `@google/genai`: متوفر للتكامل مع الذكاء الاصطناعي وMaps Grounding.
  - `express`: متوفر لبناء خادم API موحد متكامل.
  - `lucide-react`: للأيقونات التفاعلية الاحترافية.
  - `motion`: للحركات السلسة وتجربة المستخدم.
  - `tailwindcss`: للتنسيق والواجهات المتجاوبة وRTL.
  - `tsx`: لتشغيل خادم TypeScript المباشر.

## 2. القرارات المعمارية الناتجة عن التدقيق
1. **نمط النظام:** نظام متكامل أحادي (Full-Stack Monolith) يجمع بين خادم Express API قوي (`/api/v1/*`) وواجهة أمامية تفاعلية بـ React 19 مع Vite middleware mode.
2. **قاعدة البيانات:** محرك بيانات موثوق مبني بمعاملات ذرية (Atomic Transactions)، قيود فريدة (Unique Constraints)، وسلامة مرجعية (Foreign Keys Integrity) ومخزن تدقيق وسجلات تاريخية غير قابلة للحذف العشوائي، مع دعم التهيئة وإعادة البناء النظيف وحفظ الحالة.
3. **المصادقة والصلاحيات:** نظام RBAC متقدم يدعم 10 أدوار تفصيلية (زائر، مستخدم مسجل، معلن فرد، مدير منشأة، وسيط مفوض، مشرف محتوى، مسؤول امتثال وتراخيص، مسؤول دعم، مسؤول مالي، مدير نظام) مع التحقق على مستوى الخادم في كل عملية (Server-Side Authorization).
4. **دورة حياة الإعلان:** تطبيق الآلة الحالية الصارمة (State Machine) لـ 9 حالات:
   `مسودة`، `بانتظار التحقق`، `مطلوب استكمال`، `معتمد للنشر`، `منشور`، `موقوف`، `منتهي`، `مرفوض`، `ملغى` مع تسجيل السجل التاريخي `LISTING_STATUS_HISTORY`.
5. **العمليات المالية:** نظام طلبات دفع فريدة، منع التكرار (Idempotency Key)، إصدار فواتير ضريبية، إدارة الباقات، وسياسات الاسترداد المعتمدة.
6. **التكاملات الخارجية:** طبقة وسيطة مرنة (Adapters) للتراخيص والتحقق والخرائط مع دعم Google Maps Grounding للمعلومات الحية وتحليل الأحياء.
