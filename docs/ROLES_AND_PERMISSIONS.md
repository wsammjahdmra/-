# مصفوفة الأدوار والصلاحيات (ROLES & PERMISSIONS)
**منصة عقار — الإصدار الرابع**

| الدور البرمجي | التسمية العربية | نطاق الصلاحيات الأساسية | القيود والحماية الخادمة |
|---|---|---|---|
| `visitor` | زائر غير مسجل | تصفح الإعلانات المنشورة، البحث، الفلاتر، تفاصيل العقار والمشاريع، المؤشرات السوقية | لا يمكنه إنشاء إعلان، لا يرى بيانات المالك الخاصة، لا يرى إعلانات غير منشورة |
| `registered_user` | مستخدم مسجل | إدارة الملف الشخصي، المفضلة، حفظ البحث، التنبيهات، إرسال البلاغات، فتح تذاكر الدعم | لا يمكنه تعديل إعلانات الغير، لا وصول للوحة الإدارة |
| `individual_advertiser` | معلن فرد | إنشاء إعلاناته، رفع الصور، تقديم الإعلان للمراجعة والترخيص، شراء باقات الترويج، سحب الإعلان | لا يغير نتيجة التحقق الرسمي يدوياً، لا ينشر دون ترخيص معتمد |
| `org_manager` | مدير مكتب/منشأة | إدارة بيانات المنشأة، دعوة الأعضاء وتحديد نطاقهم، إدارة إعلانات المكتب، التقارير | مقيد بنطاق منشأته فقط، لا يمكنه الوصول لبيانات مكاتب أخرى |
| `authorized_broker` | وسيط مفوض | إنشاء وتعديل إعلانات المنشأة الموكلة إليه، متابعة الملاحظات | لا يمكنه إدارة الفريق أو تعديل ملف المنشأة الرسمي |
| `content_moderator` | مشرف محتوى | مراجعة الإعلانات، فحص الوسائط، قبول/رفض مع سبب إلزامي، مراجعة البلاغات | لا صلاحيات مالية، لا وصول لإعدادات النظام الحساسة |
| `compliance_officer` | مسؤول امتثال وتراخيص | فحص رخص الإعلانات وفال، مراجعة سجلات الربط الخارجي، إعادة المحاولات المتعثرة | لا يستطيع تحويل فشل التكامل إلى قبول تلقائي دون فحص |
| `support_officer` | مسؤول دعم فني | استقبال تذاكر الدعم، التصنيف، الرد، التصعيد، الإغلاق | وصول مقيد ببيانات التذكرة المعالجة فقط |
| `financial_officer` | مسؤول مالي | استعراض طلبات الدفع، الفواتير الضريبية، مراجعة وتمرير طلبات الاسترداد | لا يغير كود النظام أو صلاحيات المستخدمين |
| `system_admin` | مدير النظام | إدارة المستخدمين والصلاحيات، إعدادات المنصة والهوية والألوان، مراقبة سجل التدقيق | تطبيق مبدأ أقل صلاحية وتوثيق كل تغيير في سجل التدقيق |

### قواعد التحقق في الخادم (Server-Side Rules):
1. **التحقق من ملكية السجل (Ownership Check):** أي محاولة لتعديل أو حذف إعلان تفحص `owner_id === req.user.id` أو وجود تفويض من المنشأة المالكة للإعلان.
2. **منع التعديل المباشر لحالة الترخيص:** رقم الترخيص وحالة التحقق تتم عبر تدفق خدمة الامتثال وليس كمدخل اختياري من العميل.
3. **إلزامية السبب عند الرفض أو الإيقاف:** المشرف ملزم بإرفاق نص السبب في `LISTING_STATUS_HISTORY` عند اتخاذ أي إجراء سلبي.
